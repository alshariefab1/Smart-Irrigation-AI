# 🌿 Smart Predictive Irrigation System (نظام الري الذكي التنبؤي)

## 📌 عن المشروع (About The Project)
هذا المشروع يدمج بين **هندسة المياه والري** وتقنيات **الذكاء الاصطناعي (Machine Learning)**. 
الهدف الأساسي هو تقليل هدر المياه في المشاتل والمزارع (مثل مشتل بوتانيكا) عن طريق التنبؤ الدقيق بقيمة **البخر-نتح المرجعي (ET0)** باستخدام البيانات المناخية، دون الحاجة لتركيب محطات طقس فيزيائية مكلفة.

## ⚙️ المنهجية الهندسية (Engineering Methodology)
بدلاً من الاعتماد على الجدولة التقليدية للري، يعتمد النظام على:
1. **معادلة بنمان-مونتيث (FAO-56 Penman-Monteith):** تم استخدامها كمرجع أساسي لتدريب نموذج الذكاء الاصطناعي على فهم العلاقة بين الطاقة (الإشعاع الشمسي والحرارة) والديناميكا الهوائية (سرعة الرياح).
2. **حساب الاحتياج المائي للمحصول (ETc):** يتم تحويل الـ ET0 المتوقع إلى ETc باستخدام معامل المحصول (Kc).
3. **كفاءة الري (Irrigation Efficiency):** يتم حساب كمية الضخ النهائية بناءً على كفاءة نظام الري المستخدم (مثل الري بالتنقيط).

## 🧠 نموذج الذكاء الاصطناعي (AI Model)
* **الخوارزمية المستخدمة:** `Random Forest Regressor` (الغابة العشوائية).
* **المدخلات (Features):** درجة الحرارة العظمى والصغرى، أقصى سرعة للرياح، وإجمالي الإشعاع الشمسي (Shortwave Radiation).
* **المخرجات (Target):** التنبؤ بقيمة ET0 اليومية (ملم/يوم).
* **جلب البيانات:** يتم جلب البيانات المناخية آلياً عبر `Open-Meteo API`.

## 🚀 التطوير المستقبلي (Future Work)
لزيادة دقة النظام وتحويله إلى نظام هيدروليكي متكامل، سيتم مستقبلاً دمج عوامل التربة الثابتة في خوارزمية اتخاذ القرار، وتحديداً:
* **معامل التوصيل الهيدروليكي (Hydraulic Conductivity).**
* **حساب فواقد التسرب العميق (Deep Percolation).**
لضمان عدم تجاوز سعة الاحتفاظ المائي للتربة (Field Capacity).
